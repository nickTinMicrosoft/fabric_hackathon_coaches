# Cosmos DB grad-exam seed data

`grad-exams.json` is a ready-to-load Cosmos DB seed dataset: **27 graduate-entrance-exam
results** (LSAT, MSTAT, GRE, GMAT, MCAT) for 23 students, correlated with their
undergraduate course performance so there is a real, discoverable relationship between
undergrad grades and whether a student passes their graduate intake exam.

- **Format:** JSON array of documents.
- **Partition key:** `/studentId`.
- **Each document** includes an `undergradContext` block showing the relevant courses,
  grades, and GPA that drive the exam score.

## How to use

Load it directly into a Cosmos container (partition key `/studentId`) — no code
generation required. For example, with the loader in the `fy27_student_demos` repo
(`seeding-scripts/cosmos/load-grad-exams.py`), or any Cosmos bulk-import tool.

The data is generated by `seeding-scripts/cosmos/generate-grad-exams.py` in
`fy27_student_demos`; this copy is provided so coaches can seed **without** running Python.
